SSH and Telnet need the local companion: python switch-console-server.py. Serial does not.

Use Chrome or Edge. Serve this file from localhost. Default Cisco console is 9600 8-N-1. Log in and reach privileged EXEC (#) before polling.

Field laptop — step by step

  1. Copy switch-console-gui.html to a folder on the troubleshooting laptop, for example C:\tools\switch-gui\.
  2. Install current Google Chrome or Microsoft Edge. Firefox and Safari cannot open the serial port.
  3. Install Python 3 if it is not already present (needed only to host the file on localhost). No other application is required. The neighbor diagram is drawn in the page itself.
  4. Open Command Prompt or PowerShell in that folder and run:
    python -m http.server 8080
    Leave that window open.
  5. Browse to http://localhost:8080/switch-console-gui.html.
  6. Connect the console cable (USB-serial or the switch USB console). Install the adapter driver if Windows shows an unknown COM device (FTDI, CP210x, or Prolific).
  7. Set Platform to Cisco IOS / IOS-XE for the first tests. Baud 9600 is the usual Cisco default; try 115200 if the screen is garbage.
  8. Click Connect console and choose the COM port.
  9. If you see a username or password prompt in the black console pane, type it in the raw line at the bottom and press Enter. Then type enable (or click enable) and the enable password so the prompt ends with #.
  10. Click Poll inventory. The Dashboard faceplate, model, and port LEDs fill from show version, show interfaces status, and environment commands.
  11. Open the Neighbors tab and click Map CDP + LLDP. That runs the discovery commands and draws local port ↔ neighbor port.
  12. Use CLI library to search everyday words such as neighbors, vlan, save, or trunk. Each card shows the Cisco command and the HPE equivalent.

What you do not need

PuTTY, Tera Term, SecureCRT, and Cisco CLI Analyzer are optional. This page talks to the COM port directly. Graphviz, Visio, and Python libraries are not used for the neighbor map. Keep Python only as a tiny web server so the browser allows Web Serial.
